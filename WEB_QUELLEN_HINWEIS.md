# Cardmarket / Cardcluster

Diese Version öffnet Cardmarket und Cardcluster als Browser-Suche.

Automatisches Scraping ist bewusst nicht eingebaut. Gefundene Daten können manuell lokal gespeichert werden:

- Name
- eigene ID / Passcode
- Set-Name
- Set-Code
- Rarity
- Bild-URL oder lokaler Bildpfad
- Notiz/Beschreibung

Danach werden diese lokalen Einträge in Suche, Sammlung, Decks und Export berücksichtigt.
