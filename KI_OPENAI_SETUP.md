# OpenAI / ChatGPT Anbindung

Die App nutzt optional die OpenAI Responses API.

## Verbindung

1. Erstelle einen API-Key in der OpenAI Platform.
2. Öffne in Just InCard den Button **KI-Key**.
3. Füge den Key ein und speichere ihn lokal.
4. Öffne **Decks** und nutze **KI Deck** oder **KI-Ideen**.

Der Key wird nicht in GitHub gespeichert, sondern nur lokal auf dem Gerät.

## Was gesendet wird

Bei der Deckhilfe werden Kartennamen, Typen, Archetypes, Setcodes und Besitzmengen aus deiner Sammlung an die API gesendet.
